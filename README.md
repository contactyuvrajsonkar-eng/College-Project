**1. Problem Statement**

In our college, students need to check their class test timetable and test results. Sometimes it is difficult to get this information on time.

This website will provide the class test timetable and test results in one place. Teachers and HODs will also have separate login pages and interfaces to manage the test-related information.

**2. Users & Their Roles**
   
Student
View class test timetable.
View test results.
Check test-related information.
Teacher
Login to the teacher account.
Add and manage test timetable.
Add and update student test results.
HOD
Login to the HOD account.
View and manage department test information.
Monitor test timetable and results.

**3. UI Flow**

Home Page → Select User → Login → Dashboard

Student → Student Dashboard → Timetable / Results
Teacher → Teacher Dashboard → Manage Timetable / Results
HOD → HOD Dashboard → Manage and Monitor Information

**5. Application**

This application is a college test management website. It helps students to easily check their class test timetable and results. Teachers can manage test information and results, while HODs can monitor the test information of their department.
